# INTERNAL USE ONLY

This repository is private. It contains per-participant values derived from ADNI and A4/LEARN data
(participant identifiers, regional SUVR, Centiloid values) and, in this internal release, the reference values
used for comparison: the A4/LEARN reference values (columns `a4_*`, `suvr_a4`) and the FDG reference values
(column `leads_ref` and the reference columns of the FDG summary), which come from the laboratory's own
processing of ADNI participants.

* The README describes the public release. In this internal release the files in `data/` that list a reference
  column (`suvr_a4`, `leads_ref`, `a4_ref`, `a4_mean`, `a4_sd`, `a4_*`) also contain those reference values.
* Access is limited to named members of the laboratory who hold their own approved ADNI and A4/LEARN data
  access. Do not add anyone else, and do not make the repository public or fork it outside the laboratory.
* Do not copy the files in `data/` outside the laboratory's approved storage, and do not attach them to
  messages or manuscripts.
* Do not add imaging data or clinical data to this repository.
* Any release beyond the laboratory requires written permission from the data providers.
